# 🎬 QUΔDRA Frontend - Setup Guide

## Instalación Rápida

```bash
cd frontend
npm install
npm run dev
```

¡Eso es todo! Los videos de fondo se cargan automáticamente desde Pexels.

## Características

✅ **Videos de fondo animados** - Se alternan cada 15 segundos  
✅ **Tipografía profesional** - Inter para formularios, Playfair Display para título  
✅ **Sin overlay oscuro** - Videos completamente visibles  
✅ **Responsive design** - Funciona en mobile y desktop  
✅ **Animaciones suaves** - Transiciones elegantes  
✅ **Sin descargas** - Videos se cargan directamente desde Pexels
